# C13 – nativní katalog avionických funkcí

MSFS Companion funguje **bez MobiFlight Connectoru, WASM modulu i jiného
samostatně instalovaného programu**.

Stránka `/capabilities` ukazuje u aktuálního letadla známé Input Events
G1000, G3X, G3000 a GNS430/530 z katalogů, které už MSFS Companion
obsahoval. Jde o kandidátní události; stav „Dostupné“ se uvádí jen
u názvů skutečně enumerovaných přes SimConnect v aktuálním letu.
Katalog sám nepovoluje ani nespouští nové povely.

Projekt HubHop/MobiFlight slouží jako veřejná reference pro návrh
budoucích profilů. Neprovádíme automatický import kompletní databáze
ani nespouštíme cizí RPN kalkulační kód; jeho kompatibilitu s nativním
SimConnect i licenční podmínky je třeba pro každý typ ověřit zvlášť.
Neměnit tím existující zabezpečení a omezení příkazů.
