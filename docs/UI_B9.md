# B9 – sjednocení webového dashboardu

- Společné popisky stránek už neukazují zastaralou etapu B2/B3.
- Navigace má označení aktuální stránky i pro čtečky (aria-current).
- Diagnostika 30→20 Hz je v rozbalovacím bloku, přitom úvod
  uvádí obě frekvence příjmu a předávání.
- Zmenšená záhlaví, jednotnější panely, čitelnější sekundární text,
  zvýraznění ovládání klávesnicí a preference omezeného pohybu.
- V úzkých obrazovkách zůstává navigace vodorovně posuvná,
  PFD zachovává vlastní čitelnou vodorovnou oblast.

## Ověření UI

Otevřete /admin, /pfd, /map, /flights a /aircraft na 320px mobilu,
tabletu a desktopu. Ověřte navigaci klávesnicí (Tab, Enter),
diagnostiku včetně rozbalení, změnu stavu MSFS a nulové hodnoty.
Tato etapa nemění SimConnect zdroj ani síťovou autorizaci.
