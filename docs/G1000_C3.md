# C3 – G1000 remote / Input Events

- `/g1000` na tabletu zobrazuje PFD a MFD ovladače jako +/- a tlačítka.
- Ovládání je dostupné jen ve skutečném MSFS, když `GET /api/avionics/g1000` enumeruje odpovídající Input Events.
- Není podporováno posílání surových názvů, hashů ani RPN kódu z prohlížeče.
- `POST /api/avionics/g1000/command` vyžaduje stejné podmínky a limity jako C1/C2.
- Není-li událost dostupná, API nic neposílá; UI ovladač deaktivuje.
- Detekce se obnovuje po 30 s, a před odesláním se kontroluje aktuální `TITLE`, aby se nevykonal starý event na jiném letadle.
- MSFS Glass byl pouze referencí možných názvů; G1000 varianty a konkrétní knoby **vyžadují ověření na Windows v MSFS 2020**.
- Žádný G1000 softkey nebo knob není označen za kompatibilní bez enumerace v dané avionice.
- K ověření: C172 s Working Title G1000, enumerace, následně FMS/HDG/NAV +/-, Direct-To/Menu/CLR, změna letadla a odpojení simulátoru.

- PFD a MFD softkeys 1–12 jsou připravené jako povolené kandidátní názvy. V UI se aktivují až po enumeraci konkrétní Input Event v MSFS 2020. Bez reálné kompatibility zůstanou deaktivované.
