# Branding Kokpit

**Kokpit** je český uživatelský název pro webové doprovodné přístroje
Microsoft Flight Simulator 2020.

- Nápis: **Kokpit**.
- Podtitulek: **Virtuální kokpit · MSFS 2020**.
- Značka: stylizovaný umělý horizont/směrovka v tyrkysové a tmavě modré.
- Webové SVG favicon: `apps/web/public/kokpit.svg`.
- Lokalizace: primárně čeština.
- Lokální mDNS adresa: `kokpit.local:8765` po implementaci C12.

Identifikátor Windows instalátoru `Boym323.MsfsCompanion`, název EXE,
GitHub repository a umístění stávajících dat se nesmí přejmenovat bez
explicitní aktualizační migrace. Branding ve Windows se zapojí zvlášť
po integraci síťové etapy C12.

## Právní upozornění

Název „Kokpit“ není na trhu jedinečný. Jako pilotní vývojové označení
je srozumitelný, ale před komerčním zveřejněním je třeba rešerše u ÚPV
a EUIPO, protože existují stejnojmenné softwarové a letecké aplikace.
Tento dokument není právní posouzení ani potvrzení dostupnosti známky.
